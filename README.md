# 📊 Sales Dashboard (Microsoft Excel)

## 📌 Project Overview

This project is an interactive **Sales Dashboard** created in **Microsoft Excel** using Pivot Tables, Pivot Charts, Slicers, and Dashboard Design techniques. It provides valuable business insights by analysing sales performance across different regions, categories, customer types, salespersons, and profit metrics.

## 🎯 Dashboard Features

- 📍 Region-wise Sales Analysis
- 📦 Category-wise Sales Distribution
- 📈 Monthly Sales Trend Analysis
- 👥 Salesperson Performance
- 🏢 Retail vs Corporate Sales Comparison
- 💰 Profit Analysis by Region & Category
- 🎛️ Interactive Slicers for Dynamic Filtering

---

## 📊 Dashboard Components

### 1. Sales vs Region
- Compare total sales across different regions.
- Identify the highest-performing region.

### 2. Sales vs Category
- Analyse sales distribution by product category.
- Compare Office Supplies, Electronics, and Furniture.

### 3. Highest Month Sales
- Visualise monthly sales trends.
- Identify peak and low-performing months.

### 4. Customer Contributions
- Compare salesperson sales and profit.
- Evaluate individual performance.

### 5. Retail vs Corporate
- Compare customer types using a Doughnut Chart.
- Understand customer distribution.

### 6. Profitable Business
- Analyse profit by Region and Category.
- Identify the most profitable business segments.
